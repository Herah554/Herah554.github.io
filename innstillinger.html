Databasekonfigurasjon
Slik setter du opp gratis database:
  1. Gå til console.firebase.google.com og logg inn med Google
  2. Klikk Add project → gi det et navn → klikk deg gjennom
  3. Klikk Build → Realtime Database → Create database → velg Start in test mode
  4. Gå til Project settings (tannhjulet) → Your apps → </> Web → registrer app
  5. Kopier hele firebaseConfig-objektet og lim det inn under
